# Deploy A Hyperlane Bridge With Owl Dashboard

Hyperlane Warp Route enable you to have a permissionless, interchain token bridge. By using the Owl Dashboard, you can take advantage of smart wallets to have a gasless deployment.

Hyperlane offers various types of token bridging, namely:
* Native: the bridge uses the native chain token
* Synthetic: the bridge creates an ERC20 that represents the bridged token. This token gets minted when receiving tokens from another chain
* Collateral: the bridge locks an existing ERC20 when sending tokens, and transfers locked ERC20 when receivined tokens from another chain

In this guide, you will deploy a Hyperlane Warp Route to bridge the Sepolia native token to the Polygon Amoy chain. You will create a synthetic token on Polygon Amoy to represent the Sepolia native token. This synthetic token will be minted when bridging from Sepolia, and will be burned when bridging back to Sepolia.

## Prerequisites
* Have some native token on the first chain that you will deploy to. In this tutorial, we use Sepolia, but you could use any other supported testnet.

## Steps

### Go To The Deploy Warp Route UI
1. Go to the [Owl Dashboard](https://dashboard.owlprotocol.xyz) and create or select a project that will manage your warp route. Note that the dashboard creates a default project for you.
2. On the project page, select the "Warp Route" tab. You should then see the "Deploy Warp Route" page.

<Screenshot src={warpRoutePage} alt="warpRoutePage" />

### Select Bridge Chains And Tokens
1. In the "Token 1" box, select "Sepolia" in the chains and "Native" for the token type. Notice that the token metadata on the right gets autocompleted with the Sepolia native token's name, symbol and decimals.
2. In the "Token 2" box, select "Polygon Amoy" in the chains and "Synthetic" for the token type. Note that the synthetic token will use the token metadata defined to the right of the token lists.
3. (Optionally) set the token metadata to use a custom name and symbol. We recommend to leave the decimals as is.
4. (Optionally) set the bridge owner. By default, the owner will your project's smart wallet.

<Screenshot src={warpRouteNativeToSyntheticForm} alt="warpRouteNativeToSyntheticForm" />

### Deploy Bridge

Click on "Deploy Token Router". You should now see a table under the button. It lists the chains, token router (bridge) addresses and the deployment status. Once all of the chains are confirmed, the bridge is ready!

<Screenshot src={tokenRouteNativeToSyntheticDeployment} alt="tokenRouteNativeToSyntheticDeployment" />

### Bridge Sepolia Ether

Click on the "View on SuperBridge" button at the bottom of the deployment table. It should take you to a bridge app similar to [this one](https://hyperlane.superbridge.app/?hyperlaneWarpRoutes=1e75b769-74bd-4ac3-9582-ae21b96002f2&fromChainId=11155111&toChainId=80002).

Notice that the "from" chain is already set to the "Token 1" chain, and the "to" chain is already set to the "Token 2" chain.
